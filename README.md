# Probe-Geometry Alignment: Erasing the Cross-Sequence Memorization Signature Below Chance

Code, figures, and raw results for the paper on cross-sequence memorization probing in transformers, the causal-separability finding, and the constructive method (probe-geometry alignment, PGA).

This repository contains every notebook used to produce the quantitative claims in the paper, all figures generated by those notebooks, and all JSON output files from each experimental run. Filenames below match what the paper references.

Each notebook has an "Open in Colab" badge in its first cell — clicking the badge launches it directly in Colab from this GitHub URL.

---

## TL;DR

Concurrent work has begun documenting that behavioural unlearning leaves internal traces (Chen et al. 2025; Xu et al. 2025; Hu et al. 2024; Zhang et al. 2025). This paper sharpens that picture with four contributions:

1. **A leave-one-out cross-sequence probing protocol** that tests whether the memorization signature *generalizes* across held-out sequences. On Pythia-70M, GPT-2-medium, and Mistral-7B the signature gives memorization-specific gaps of `+0.32`, `+0.19`, `+0.30` over a pure-distinguishability baseline, against a random-initialization control (Pythia-70M) whose deep-layer gap collapses to `−0.04` at L6, where the pretrained signature peaks (mean trans-layer gap `+0.19`, dominated by L0/L1 token-identity propagation).
2. **Direct evidence that the probe direction is causally separable from recall.** Projecting it out collapses the signature locally (`+0.44 → −0.19`) but it is reconstituted downstream, while behavioural recall barely changes (≤ `0.19` nats drop).
3. **A regime distinction.** A probe trained on naturally memorized content does not classify fine-tuning-injected secrets as memorized; the two regimes leave representationally distinct traces.
4. **Probe-geometry alignment (PGA), the first surgical erasure method to drive cross-sequence probes below random chance.** PGA aligns activations along the probe's own readout direction at each depth — `1`-D per depth, not the full residual. Collapses to `0.65` on toy (depth-4: `0.17`), `0.29` on Pythia-70M (L5; `0.14` at L6), `0.42` on Mistral-7B mid-layers, and `0.06` via MD-PGA k=2 on GPT-2 Medium. Robust to six adversarial probe variants. Adversarial PGA (iterative orthogonal subspace augmentation) extends the method to defeat re-fit probes while preserving five zero-shot capability benchmarks (HellaSwag, PIQA, BoolQ, ARC-Easy, WinoGrande) within 2.9 percentage points.

For mechanistic verification we use a controlled toy transformer where causal attribution is unambiguous: six unlearning methods (GA, NPO, SimNPO, RMU, IDK, and a split-objective method we introduce, MLDU) drive `P(secret)` below `10⁻⁴` while a matched-prefix decoy probe retains `1.000`. This single-sequence saturation pattern is what motivates the LOO protocol.

The paper's GPT-2-medium headline result (`+0.191` trans-layer gap, `+0.449` peak at L21) is characterised across three independent variance sources — probe-init (5 seeds, ±0.0000), context bootstrap (100 replicates, 95% CI `[+0.184, +0.196]`), sequence jackknife (all 7 gaps strictly positive, range `[+0.095, +0.250]`) — plus a single-seed register-vs-memorization control showing only `14.9%` of unmemorized legalese is classified as memorized at the peak-gap layer.

### MLDU-E (constructive erasure follow-up)

| Notebook | Stage | Primary experiments |
|---|---|---|
| `MLDU_E_phase1_retrain.ipynb` | Setup | Train new toy (4 layers, 8 heads, d_model=128) memorizing 9 distinct secrets and learning template on 9 clean prefixes with random codes per epoch. Saves `phase1_checkpoint_9plus9.pt`. |
| `MLDU_E_probe_9plus9.ipynb` | Toy evaluation | Cross-sequence LOO probe baseline on 9+9 model; tests embedding rank-k projection (k=1, 5, 20), multi-depth projection (k=1, 5), and MEMIT on all 9 prefixes × 4 layers. Shows MEMIT illusion-of-erasure (recall ↓99.99%, probe unchanged). |
| `MLDU_E_combined_attack.ipynb` | Toy ablation | Stacks MEMIT with multi-depth projection (k=5, 10, 20, 30) to map the recall-vs-probe Pareto frontier. Probe collapse chance requires 5.8× PPL cost. |
| `MLDU_E_distill.ipynb` | Toy evaluation | Trains a clean-teacher (random codes for all 18 prefixes), distils memorized student toward it. Output match achieved (P=2.7e-5, PPL=1.41) but probe stays at 0.95 — representation-level illusion. |
| `MLDU_E_aae.ipynb` | Toy evaluation | Activation-alignment erasure: full-residual L2 alignment of paired mem/clean activations at probed position. Hits all three criteria (P=2.5e-4, probe=0.70, PPL=1.40) but mechanism is FitNets-style. |
| `MLDU_E_pga.ipynb` | **Toy headline** | **Probe-geometry alignment**: aligns only along the probe's live-updated readout direction (1-D per depth). Sweeps λ ∈ {0.1, 1.0, 10.0}; best λ=0.1 gives min P=5.7e-4, max probe=0.65, PPL=1.42, with depth-3,4 below 0.5 random baseline. Includes 6-variant adversarial probe-shopping check (worst case 0.661). |
| `MLDU_E_pga_pythia70m_full.ipynb` | **Scaling** | PGA via LoRA r=16 on Pythia-70M (7 memorized + 7 clean). Peak probe 0.929 → 0.286 at L5 / 0.143 at L6; 6-variant probe-shopping check at memorization-relevant depths (worst case 0.71). Saves LoRA adapter. |
| `MLDU_E_clpa.ipynb` | Ablation | Causally-localized PGA: align only at NCE-thresholded heads (3 of 32). Suppresses recall (P=2.5e-5) but probe stays at 0.83 — confirms full-residual coverage is required, not just causal localization. |

### Post-submission controls (revision pass)

| Notebook | Stage | Primary experiment |
|---|---|---|
| `MLDU_E_register_control.ipynb` | **★ Exp 1 control** | Register-vs-memorization confound test on GPT-2 medium. Trains the LOO probe on memorized legal text, evaluates without retraining on 19 register-matched but unmemorized synthetic licenses. Verdict: 14.9% of unmemorized legalese classified as memorized at peak-gap L21, 7.0% at L24 — well below the 30% confound threshold. The signature is memorization-specific. |
| `MLDU_E_steering_attack.ipynb` | **★ Exp 2 supplement** | Residual-stream steering on Pythia-70M. Adds α·ŵ to residual at peak-gap L4 and sweeps α ∈ {−16, …, +16}, comparing vs random unit-vector control (cos(ŵ, r̂) = 0.0487). Quantifies that ŵ-steering is ≈25–28% more efficient than random at iso-α with comparable PPL cost; consistent with Finding 22 that the probe direction is partially causal but not load-bearing for recall. |

The MLDU-E pipeline is intended to be run in this order: `phase1_retrain` → `probe_9plus9` → `aae` / `pga` / `clpa` (independent comparisons) → `combined_attack` / `distill` (additional ablations) → `pga_pythia70m_full` (scaling). Post-submission controls (`register_control`, `steering_attack`) are independent of the main pipeline and can be run standalone.

The four `gpt2m_*` / `mistral7b_multiseed` notebooks reuse cached activation tensors (`activations_base.npz`, `activations_mistral7b.npz`) between runs. Run `gpt2m_multiseed` first so `gpt2m_bootstrap` and `gpt2m_jackknife` can pick up the cache without re-extracting.

## Reproducing the results

### Requirements

The notebooks were run on Google Colab (T4 for small models, L4 or A100 for Mistral-7B).

- Python 3.10+
- `torch` >= 2.0, `transformers` >= 4.34
- `numpy`, `scipy`, `scikit-learn`, `matplotlib`, `seaborn`
- `peft` >= 0.5 for MLDU-E LoRA fine-tunes (`MLDU_E_pga_pythia70m_full.ipynb`)
- `bitsandbytes` only if running Mistral-7B or other 7B models on T4 (triggers 4-bit fallback)

Mistral-7B requires Hugging Face authentication (visit the model card, accept the licence, create a read-token, store it as the `HF_TOKEN` Colab secret).

### Running

Each notebook is standalone. Open in Jupyter or Colab and run all cells top to bottom. Results write to `results/`, figures write to `figures/`. Order of execution does not matter for parent-paper notebooks 01–05; notebook `06_orphan_figures.ipynb` depends on JSON outputs from 02, 03, 04, and 05 — run it last. MLDU-E notebooks should be run in the order listed above (`phase1_retrain` first to produce the checkpoint, then any of the evaluation notebooks).

The four parent-paper robustness notebooks (`gpt2m_multiseed`, `gpt2m_bootstrap`, `gpt2m_jackknife`, `mistral7b_multiseed`) cache activations on first run. Run `gpt2m_multiseed` first so `gpt2m_bootstrap` and `gpt2m_jackknife` reuse `activations_base.npz`.

## Known caveats

- **R3C feasibility pilot** tested five configurations and all failed (target suppression came at 57× to 5920× perplexity cost). This is itself a reported finding, not a negative result omitted from the paper.
- **MLDU-E GPT-2 medium partial collapse:** PGA on GPT-2 medium (d_model=1024) reaches peak probe 0.726 — above the 0.50 random baseline. We attribute this to the sample-complexity vs. hidden-dimension ratio (N=84 effective paired samples after context augmentation, vs. d_model=1024). Larger paired pools should close this gap; see paper Appendix MLDU-E Limitations (i).
- **MLDU-E Mistral-7B capability metric:** held-out PPL on clean prefixes is preserved but broader benchmarks (GSM8K, MMLU, coding tasks) are not measured; CE on training set drops to 0.13, consistent with LoRA overfitting to the small paired set.
